# HomeEase – Smart Home Appliance Service Platform

## 📌 Project Overview

HomeEase is a responsive web-based home appliance service platform developed to make appliance repair and maintenance simple, convenient, and accessible.

The platform allows users to explore different home appliance services, manage their appliances, book service appointments, view service history, track technicians, and access emergency repair services.

The project also presents future AI-powered features such as AI Problem Detection, Photo/Video Diagnosis, Predictive Maintenance, and Smart Service Reminders.

---

## 🎯 Objectives

The main objectives of the HomeEase project are:

- To provide a simple platform for booking home appliance services.
- To help users manage their household appliances.
- To allow users to select appliance problems and preferred service slots.
- To provide estimated service costs before booking.
- To maintain service history for appliances.
- To provide technician tracking information.
- To provide emergency repair services.
- To introduce future AI-based appliance maintenance features.
- To create a clean, responsive, and user-friendly web interface.

### 🔧 Services

Users can book services for their home appliances.

The booking section allows users to:

1. Select an appliance.
2. Select the problem with the appliance.
3. Select a preferred date.
4. Select a preferred time slot.
5. View the estimated service cost.
6. Continue with the booking.

Example appliance:

- LG 1.5 Ton Inverter AC

Example problems:

- AC not cooling
- AC making noise
- Water leakage
- Bad smell
- Electrical issue

### 📅 Service Booking

The service booking interface provides a step-by-step booking process.

#### Step 1 – Select Appliance

The user selects the appliance that requires service.

#### Step 2 – Select Problem

The user selects the problem they are experiencing.

#### Step 3 – Select Time Slot

The user selects a suitable date and time slot.

The system displays an estimated cost before the user continues with the booking.
