# HomeEase - ANITS Website Project

A responsive frontend prototype for a home appliance service and booking platform.

## Features
- Home page with popular services
- Service search
- Appliance management
- Service booking UI
- Problem and time-slot selection
- Estimated cost
- Service history
- Service tracking
- Technician information
- Emergency service section
- Future AI feature cards
- Responsive design for mobile and desktop

## Technologies
- HTML5
- CSS3
- JavaScript

## How to run
1. Download/clone the repository.
2. Open the `anits` folder.
3. Double-click `index.html`, or open it with VS Code and use Live Server.

## Project structure
```text
anits/
```

## Note
This is a frontend project. Booking, login, payments, database, maps and real technician tracking would require a backend/API integration.
